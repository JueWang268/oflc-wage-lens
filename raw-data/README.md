# Official wage downloads

Download the official wage ZIP from https://flag.dol.gov/wage-data/wage-data-downloads
into this folder and extract it into a year-specific subfolder. Follow
../UPDATING_DATA.md to validate and rebuild the bundled dataset before reloading
the extension. Copying a ZIP here alone does not change wage calculations.

Raw ZIPs and extracted source files are ignored by Git and excluded from release
packages. Keep this README; do not commit private documents in this directory.
